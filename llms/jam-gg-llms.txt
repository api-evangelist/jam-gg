# Jam.gg

> Jam.gg (founded 2020 in Paris as Piepacker, rebranded 2022) built a browser-based cloud
> gaming platform for playing retro and indie multiplayer games with friends with no download,
> using patented technology the company said cut bandwidth requirements by roughly 15x. It
> reached over 8 million users before pivoting to a B2B cloud-gaming-technology model.
> Y Combinator (W20) now lists the company as **Inactive**; the business split into two
> entities in 2023, with Onibi emerging as a separate company. The jam.gg website no longer
> completes a TLS handshake and piepacker.com has left DNS.
>
> This file is GENERATED by API Evangelist from the artifacts in this repository. Jam.gg does
> not publish an llms.txt of its own — the probe of https://jam.gg/llms.txt failed at the TLS
> layer, not with a 404.

## Developer libraries

Jam.gg's surviving developer surface is its GitHub organization, whose display name is "Jam.gg"
but whose slug is still the pre-rebrand `piepacker`.

- [GitHub organization](https://github.com/piepacker): 43 public repositories, mostly forks of
  libretro emulator cores (swanstation, mupen64plus_next, dolphin, mame, mgba, mesen, dosbox_pure,
  ppsspp, RetroArch) plus WASM build tooling — the emulation stack behind the browser platform.
- [JamPadCompose](https://github.com/piepacker/JamPadCompose): Compose Multiplatform virtual
  gamepad library, Apache-2.0. Published to Maven Central as
  `io.github.piepacker:jampadcompose:0.1.0-alpha4` (2025-03-31) with android/desktop/iOS variants.
  The most recently maintained first-party artifact.
- [JamSDK-Public](https://github.com/piepacker/JamSDK-Public): "Software Development Kit for games
  on Jam.gg". A C# P/Invoke binding over a native `jam_sdk` library exposing the session context
  the platform injects into a hosted game: `get_cluster_name`, `get_connection_host`,
  `get_player_idx`, `get_session_id`, `get_user_session_id`, `set_env_path`. An FFI surface, not
  an HTTP API. Last push 2022-12-13. No license file.
- [PiepackerUnityPlugin](https://github.com/piepacker/PiepackerUnityPlugin): Unity WebGL JsLib
  bridge exposing SessionID, UserSessionID, UserID, PlayerIdx, ClusterName, ConnectionHost,
  DisplayName. MIT. Last push 2022-05-13.
